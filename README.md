# sql-supply-chain-data-warehouse
A supply chain data warehouse built with medallion architecture (bronze/silver/gold), featuring a two-fact galaxy schema that links sales and procurement processes through a shared product dimension. Built in DuckDB, modeled from a 5-table Kaggle dataset, and visualized in Power BI.
